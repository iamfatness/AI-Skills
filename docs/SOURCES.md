# Sources and provenance

Reviewed 2026-11-11. These are discovery and format references, not vendored dependencies. No third-party skill code or prose is bundled.

- [Skill Issue](https://skill-issue.in/): discovery of UI, accessibility, frontend performance, and API design themes. Its rankings are not validation; some entries are explicitly unverified. This release uses original workflows rather than copying linked packages.
- [Codex skills](https://developers.openai.com/codex/skills/): SKILL.md discovery format.
- [Claude Code skills](https://code.claude.com/docs/en/skills): project skills under .claude/skills.
- [Cursor rules](https://prod.cursor.com/docs/rules): .mdc project rules and activation metadata.
- [GPT configuration](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts): instructions and reference knowledge have separate roles; availability varies by account.

Compatibility means generated instruction formats and tested installation behavior. Live execution inside every vendor product is not certified. No adapter adds tools or bypasses host permissions. Recheck vendor documentation when upgrading host applications.
