# Evidence Research

## Inputs

A question, decision context, freshness needs, and available sources.

## Workflow

1. Define what evidence would resolve the question. Search connected project sources before broad web research when relevant.
2. Prefer primary documentation and dated source material. Check actual source content rather than relying on search snippets.
3. Compare conflicting claims, versions, and dates. Separate sourced facts from inference and unresolved questions.
4. Provide direct supporting links and concise paraphrases. If browsing is unavailable, label knowledge limits and do not invent citations.

## Output

An answer with supporting sources, dates where relevant, and implications for the decision.

## Example

Compare two documented API authentication options for an existing integration.
