# Task Planning

## Inputs

A requested outcome plus constraints and any existing project plan.

## Workflow

1. Inspect existing plans and identify the smallest complete deliverable. Separate required work from optional improvements.
2. Map dependencies and uncertainty. Investigate inexpensive unknowns before asking the user to decide.
3. Define acceptance evidence for each material outcome and identify external actions requiring authorization.
4. Execute the next ready step when implementation is requested; update the plan when evidence changes scope.

## Output

A concise ordered plan, assumptions, acceptance evidence, and any blocking decision.

## Example

Plan a safe migration of a settings file while preserving user overrides.
